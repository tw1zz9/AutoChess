# Magic Auto Chess

Локальная игра в жанре Auto Chess для двух игроков.

## Правила игры

### Стартовые условия
- Каждый игрок получает: 3 Trickster, 2 Tank, 2 Mage, 1 Healer
- Стартовое золото: 0 монет
- Игровое поле: 5x2 клетки для каждой команды

### Экономика
- **Апгрейд юнитов:**
  - 1→2 уровень: 10 золота
  - 2→3 уровень: 20 золота
  - 3→4 уровень: 30 золота
- **Ультимейты:** 5 золота
- **Награда за раунд:** 5 + (номер раунда - 1) × 2 золота

### Фазы игры
1. **Подготовка:** Расстановка юнитов на поле 5×2, апгрейды, выбор целей, активация ультимейтов
2. **Бой:** 3 раунда автоматических атак (все юниты атакуют одновременно)
3. **Повтор:** Новый раунд с наградами, пока у кого-то есть живые юниты

### Механика боя
- **3 раунда атаки** за каждый бой
- **Автоматический выбор целей** если цель не выбрана или мертва
- **Ультимейты активируются вручную** в фазе подготовки (5 золота)
- **Массовое лечение** доступно для хилеров с активным ультимейтом

### Персонажи

#### Tank (Танк)
- **Здоровье:** 1000 | **Броня:** 15 | **Урон:** 100
- **Ультимейт (5 золота):** Taunt - все вражеские атаки направляются на него весь бой

#### Mage (Маг)
- **Здоровье:** 500 | **Броня:** 3 | **Урон:** 150
- **Ультимейт (5 золота):** Arcane Surge - удваивает урон всем союзникам весь бой

#### Healer (Лекарь)
- **Здоровье:** 800 | **Броня:** 8 | **Лечение:** 100
- **Ультимейт (5 золота):** Divine Light - лечит всех союзников каждый раунд

#### Trickster (Трикстер)
- **Здоровье:** 650 | **Броня:** 5 | **Урон:** 200 | **Уклонение:** 25%
- **Ультимейт (5 золота):** Shadow Step - 100% уклонение весь бой

## 🚀 Запуск и тестирование

### Быстрый старт:
1. **Открыть проект в Unity** (версия 2021+)
2. **Открыть сцену:** `Assets/Scenes/SampleScene.unity`
3. **Запустить игру:** `Ctrl+P` или кнопка Play

### 🧪 Тестирование функциональности:

#### Вариант 1: Простой тест
- Добавьте `SimpleGameTest` компонент на любой объект в сцене
- Создайте UI кнопки и TextMeshPro поля для отображения статуса
- Нажмите "Создать юнитов" → "Начать бой" → "Сбросить"

#### Вариант 2: Ручное тестирование
```csharp
// В любом скрипте можно протестировать:
var tank = UnitFactory.CreateTank(Team.Blue);
tank.LevelUp();
Debug.Log($"Tank Level {tank.Level}, Damage {tank.Damage}");
```

#### Вариант 3: Полная игра (рекомендуется)
1. **Создайте пустой объект** `GameController`
2. **Добавьте компоненты:**
   - `GameManager` (основной менеджер игры)
   - `TestSceneSetup` (для удобного тестирования)
3. **Создайте UI Canvas:**
   - Text: "Раунд X" (привяжите к Round Text)
   - Text: "Фаза: X" (привяжите к Phase Text)
   - Text: "Статус" (привяжите к Status Text)
   - Button: "Создать юнитов" (привяжите к Create Units)
   - Button: "Разместить юнитов" (привяжите к Place Units)
   - Button: "Игрок 1 Ready" (привяжите к Player 1 Ready)
   - Button: "Игрок 2 Ready" (привяжите к Player 2 Ready)
4. **Запустите сцену** и тестируйте:
   - Создайте юнитов → Разместите на поле → Нажмите Ready обоим игрокам
   - Смотрите логи в Console для отладки

### 🐛 Отладка:
- Все логи выводятся в Unity Console (`Ctrl+Shift+C`)
- Проверяйте `GameManager.Instance` на null
- Используйте `Debug.Log()` для отслеживания состояний

### 🎮 Запуск игры:

#### Создание сцены:
1. **Создайте объект** `GameController` → **Add Component** → `GameManager`
2. **Создайте объект** `GameUI` → **Add Component** → `GameUI`
3. **Создайте объект** `BoardVisualizer` → **Add Component** → `BoardVisualizer`
4. **Создайте два объекта инвентаря:**
   - `BlueInventory` → **Add Component** → `InventoryUI` (Team = Blue)
   - `RedInventory` → **Add Component** → `InventoryUI` (Team = Red)
5. **Создайте UI Canvas:**
   - **GameUI Component** на Canvas для общей информации
   - **InventoryUI Components** на отдельных панелях для каждого игрока
   - Кнопки Ready для каждого игрока
6. **Запустите игру** - полная визуальная система готова!

#### Что отображается в игре:
- ✅ **Раунд и фаза** игры (центр)
- ✅ **Золото каждого игрока** (в инвентарях)
- ✅ **Юниты в инвентаре** (список с возможностью выбора)
- ✅ **Информация о юните** (статистика, апгрейды, ультимейты)
- ✅ **Кнопки размещения** юнитов на поле
- ✅ **Здоровье юнитов** (текст над головами, обновляется в реальном времени)
- ✅ **Визуальные юниты** (цветные кубики на поле)
- ✅ **Активация ультимейтов** за золото
- ✅ **Статус игры** (подготовка/бой/окончена)

#### Настройка InventoryUI компонента:
1. **Выберите панель инвентаря**
2. **Add Component** → **InventoryUI**
3. **Заполните поля в Inspector:**
   - `Player Team` - Blue или Red
   - `Gold Text` - TextMeshPro для золота
   - `Player Name Text` - название игрока
   - `Unit Slots` - массив InventorySlotUI компонентов
   - `Ultimate Button` - кнопка активации ультимейта
   - `Ultimate Cost Text` - стоимость ультимейта
   - Кнопки и панели для информации о юнитах

#### Настройка BoardVisualizer:
1. **В Inspector BoardVisualizer:**
   - `Cell Prefab` - перетащите префаб клетки (или используйте PrefabCreator)
   - `Tank/Mage/Healer/Trickster Prefab` - перетащите префабы юнитов
   - `Blue/Red Team Area` - создайте пустые объекты для позиционирования команд
2. **Создайте области команд:**
   - `BlueTeamArea` (позиция X: -5, Z: 0)
   - `RedTeamArea` (позиция X: 5, Z: 0)

#### Создание префабов:
1. **Создайте объект** `PrefabCreator` → **Add Component** → `PrefabCreator`
2. **В контекстном меню** (шестеренка) → **Create Basic Prefabs**
3. **Префабы появятся** в папке `Assets/Prefabs/`
4. **Или создайте вручную:**
   - **Cell:** Quad + BoxCollider + CellView (серый цвет)
   - **Units:** Cube + UnitView (разные цвета)
   - **Здоровье:** TextMesh автоматически добавляется при размещении юнитов
