# Auto Chess - RayLib Version

Полная переработка игры Auto Chess с Unity на C# с использованием RayLib.

## 🚀 Запуск

### Требования
- .NET 6.0 или выше
- RayLib-cs NuGet пакет (автоматически устанавливается)

### Сборка и запуск
```bash
# Перейдите в папку проекта
cd RayLibAutoChess

# Соберите проект
dotnet build

# Запустите игру
dotnet run
```

### Что происходит при запуске
1. Проект автоматически скачивает и устанавливает RayLib-cs
2. Компилируется весь исходный код игры
3. Запускается окно игры размером 1200x800 пикселей
4. Игра готова к демонстрации!

## 🎮 Как играть

1. **Фаза подготовки**: Размещайте юнитов на поле кликом мыши
2. **Нажмите SPACE**: Готовность обоих игроков и начало боя
3. **Автоматический бой**: Юниты сражаются автоматически
4. **Повторение**: Раунды продолжаются до победы

## 🎯 Возможности

### Юниты
- **Mage**: Магический урон, усиление команды
- **Tank**: Танк, защита союзников
- **Trickster**: Уклонение от атак, скрытность
- **Healer**: Лечение союзников, массовое лечение

### Система
- Автоматический бой между командами
- Экономика и апгрейды юнитов
- Система ультимативных способностей

## 🛠️ Управление

- **Левый клик мыши**: Разместить юнита на поле
- **Пробел**: Готовность игроков и начало боя
- **ESC**: Выход из игры

## 📁 Структура проекта

```
RayLibAutoChess/
├── src/
│   ├── Core/           # Базовые интерфейсы и типы
│   ├── Entities/       # Классы юнитов
│   ├── Combat/         # Система боя
│   ├── Economy/        # Экономика игры
│   ├── Field/          # Игровое поле
│   ├── Player/         # Инвентарь игроков
│   ├── Render/         # Графический интерфейс RayLib
│   └── Factories/     # Фабрики создания юнитов

├── bin/              # Скомпилированные файлы
└── README.md
```

## 🎨 Графика

Игра использует простую 2D графику RayLib:
- Белое поле 5x1 клеток
- Синие и красные круги для юнитов
- Текстовый интерфейс для информации об игроках
